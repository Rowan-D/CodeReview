# AI Agent Guidelines
This document defines machine-readable instructions for AI coding agents.

## Performance
Always consider performance when making implementation decisions.

## Changes
Do not claim that code works, passes tests, or has been verified unless it was actually checked.

## Git Rules
* Commit messages should be formatted with the 50/72 rule: 50 is the maximum number of characters of the commit title, and 72 is the maximum character length of the commit body.
* Do not push directly to `main` unless explicitly asked.

## Documentation and Voice
* Write in an informational style.
* Be concise and direct. Avoid unnecessary repetition, filler, and excessive explanation.
* Do not write as if speaking on behalf of the user or repository owner.
* Do not use first-person voice such as `I`, `we`, `my`, or `our` unless explicitly instructed.
* Do not imply that the user personally wrote, reviewed, tested, or approved the content unless explicitly confirmed.
* Prefer phrases like `the project`, `this repository`, `the application` over personal language.

## External Actions and Identity
* Do not post, publish, comment, message, or otherwise communicate online on behalf of the user.
* Do not represent AI-generated statements as statements personally made by the user.
* Do not create issues, pull requests, releases, discussions, or other public-facing content under the user's identity.

## Attribution and Transparency
Do not hide that the project is AI-generated.
